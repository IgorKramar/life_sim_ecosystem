Наблюдайте, как на клеточном поле растут растения, кормятся травоядные и охотятся хищники. Агенты расходуют энергию, стареют, размножаются и умирают; на экране видны популяция, растения, средняя энергия и поколение. Версия **0.0.3** — экспериментальная симуляция, а не научно подтверждённая модель экологии.

## Устройство мира

| Система | Поведение |
|:---|:---|
| Растения | Случайный рост обеспечивает травоядных энергией |
| Травоядные | Питаются, ищут партнёров и мигрируют при скученности |
| Хищники | Охотятся на травоядных и получают энергию за убийство |
| Агенты | Хранят пол, возраст, энергию, родителей, поколение и семейный корень |
| Наблюдение | Пауза, перезапуск, изменение скорости и численность поколений |
| Баланс | Размер мира, популяция, пища, энергия и размножение задаются через TOML |

## Запуск

Нужны актуальный стабильный Rust и графическая среда, совместимая с Macroquad. Минимальная поддерживаемая версия Rust в манифесте не закреплена.

```sh
git clone https://github.com/IgorKramar/life_sim_ecosystem.git
cd life_sim_ecosystem
cargo run --release --locked
```

Запускайте из каталога репозитория, чтобы использовать его [config.toml](config.toml). Если файла нет в рабочем каталоге, приложение пытается создать его с настройками по умолчанию. Ошибка чтения или разбора выводится в терминал, после чего используются значения по умолчанию.

Отдельно доступны [опубликованные релизы](https://github.com/IgorKramar/life_sim_ecosystem/releases); подходящую сборку проверяйте в файлах конкретного выпуска.

## Управление

| Клавиша | Действие |
|:---|:---|
| `P` / `Space` | Пауза или продолжение |
| `R` | Создать мир заново с уже загруженными настройками |
| `G` | Показать или скрыть численность поколений |
| `=` / `+` | Ускорить; предел по умолчанию — около 100 тиков/с |
| `-` | Замедлить; предел по умолчанию — 2 тика/с |
| `Q` / `Esc` | Выход |

Фактическая скорость зависит от отрисовки и оборудования. Для ускорения обработчик клавиатуры использует код клавиши `Equal`.

## Конфигурация

Измените [config.toml](config.toml), затем **закройте и снова запустите программу**. Перекомпиляция не нужна. `R` пересоздаёт агентов, но не перечитывает файл; загрузки настроек на лету нет.

| Раздел | Параметры |
|:---|:---|
| `world` | Ширина и высота сетки |
| `population` | Начальная численность, доля травоядных и порог скученности |
| `plants` | Попытки роста, прирост и предел энергии |
| `herbivore`, `predator` | Начальная энергия и энергия рождения, возраст, движение и размножение; награды и штрафы охоты |
| `common` | Миграция, радиус поиска партнёра и затраты размножения |
| `genetics` | Переключатели проверки родства и настройки генеалогии |
| `timing` | Начальный интервал тика, пределы и множители скорости |
| `render` | Размер клетки, пределы размера агента и прозрачность растений |

В сохранённом конфиге доля травоядных равна **0.65**. В `Config::default()` используется **0.95**: удаление файла изменяет начальный баланс.

<details>
<summary><strong>Три эксперимента с балансом</strong></summary>

Перенесите значения в соответствующие разделы существующего файла. Эти фрагменты не заменяют полный конфиг.

**Hardcore — усилить хищников**

```toml
[predator]
kill_reward = 200
hunt_fail_penalty = 1

[herbivore]
reproduce_min_energy = 100
```

**Garden — больше растений и травоядных**

```toml
[plants]
growth_attempts = 100
max_energy = 200

[population]
herbivore_spawn_ratio = 0.99
```

**Big World — увеличить поле**

```toml
[world]
width = 200
height = 150

[population]
init_population = 300
```

</details>

## Визуальные обозначения

| Объект | Цвет | Форма |
|:---|:---|:---|
| Растение | Зелёный; прозрачность отражает энергию | Квадрат |
| Травоядный: самец / самка | Синий / голубой | Круг |
| Хищник: самец / самка | Красный / тёмно-красный | Круг |

Размер агента отражает энергию в пределах, заданных настройками отрисовки.

## Генеалогия и ограничения

Каждый агент хранит `parent1_id`, `parent2_id`, `generation` и `family_root`. Начальные агенты относятся к нулевому поколению. Клавиша `G` показывает количество живых агентов каждого поколения.

Проверка родства **эвристическая**: сначала сравниваются семейные корни, затем родители и общие родители. Опция проверки бабушек/дедушек блокирует пару с одинаковым корнем и разницей поколений не меньше двух; полного обхода родословной нет. Родство между разными корнями может быть пропущено. `max_genealogy_depth` есть в конфиге, но текущая проверка его не использует.

Сохранение и загрузка мира, экспорт CSV, наследуемые мутации и ландшафт пока не реализованы. Вместе с переключением пресетов на лету, графиками популяции, записью видео и ручным размещением объектов они остаются идеями развития.

## Разработка

```sh
cargo check --locked
cargo clippy --locked -- -D warnings
cargo test --locked
cargo run                 # отладочная сборка
cargo run --release       # оптимизированная сборка
cargo clean               # удалить результаты сборки
```

Перед предложением изменений выполните проверки, проверьте релизную сборку и обновите описание конфигурации при добавлении параметров. Существующий workflow запускает сборку и тесты.

| Файл | Ответственность |
|:---|:---|
| [src/main.rs](src/main.rs) | Цикл приложения и управление |
| [src/config.rs](src/config.rs) | Загрузка конфигурации и значения по умолчанию |
| [src/agent.rs](src/agent.rs) | Агенты, размножение и родство |
| [src/world.rs](src/world.rs) | Обновление мира и популяция |
| [src/render.rs](src/render.rs) | Отрисовка Macroquad |

Зависимости в [Cargo.toml](Cargo.toml): Macroquad `0.4.14`, rand `0.10.0`, Serde `1.0`, TOML `0.8`; точные разрешённые версии находятся в `Cargo.lock`.
